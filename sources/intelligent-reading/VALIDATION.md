# 插件包校验说明

版本：1.0.0。范围为可上传的个人插件 ZIP；未执行账号上传、安装、公开目录审核或宿主中的端到端行为测试。

## 执行的检查

- 使用 Agent Plugins 1.0.0 官方 JSON Schema 校验根清单。
- 检查名称、语义版本、YAML 前置字段及插件展示字段长度。
- 运行 book-to-skill 原技能格式验证器与原生成内容扫描器。
- 原扫描器不覆盖 provenance.md；补充调用其相同规则检查包内全部 Markdown。
- 检查 Markdown 相对链接、21章索引与编号连续性。
- 检查图标实际为256×256 PNG、文件大小与清单路径。
- 核对原输入 SHA-256 与提取元数据一致。
- 检查压缩包仅有一个顶层插件目录，检查解压路径与成员清单。
- 检查包内不包含原 EPUB、正文提取文件、临时脚本、凭据或绑定外部应用的文件。

本说明随最终打包流程一并核对。自动扫描只检查已知模式，不能保证内容绝对正确或平台审核通过。当前结果不等于已在目标宿主安装验证。

## 使用与公开上架

个人插件上传通常由宿主读取 plugin.json 与 skills/。公开上架还需要真实发布者身份与对应公开页面等信息；用户尚未提供这些内容，清单没有填入虚构值或占位网址。
