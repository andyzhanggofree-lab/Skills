# Book-to-Skill 个人插件适配版 0.1.1

把书籍或文档转换为可按需读取的知识 Skill。基于 virgiliojr94/book-to-skill 的 MIT 源码。
这不是原项目官方发布的插件，不包含书籍内容。

## 安装

1. 在插件页面点击「添加 → 上传插件压缩包」。
2. 选择 book-to-skill-plugin-0.1.1.zip（不要再次压缩或解压后上传）。
3. 等待平台扫描，查看实际检查结果，再完成安装。
4. 在新对话/任务中选择主技能 book-to-skill，直接提交书籍或文档；主技能会在转换前检查环境。
5. 若平台提示结构或元数据问题，保留提示交给 Codex 调整；本地验证不能代替平台扫描。

压缩包根目录就是 plugin.json、skills/ 等内容，没有多余外层项目目录。
使用标准 Agent Plugins manifest，skills/ 为默认发现目录。
不含本机 MCP 服务、自动执行 hooks 或 Mac 专用工具。

## 先测试

新建具备文件、命令执行与 Python 的 Codex 云端任务，启用插件，提供短 Markdown：

> 请使用 book-to-skill 处理附件，用中文生成测试 Skill。
> 输出到当前工作区 book-skills/test-book，暂时不修改 Obsidian 或推送 GitHub。
> 列出读取范围、文件路径、校验结果与限制。

然后问一个文档中的具体问题，要求先读取生成章节文件并说明出处。
输入只有书名时不代表能读取正文；普通聊天可能没有运行脚本所需工具。

## 跨设备与更新

手机和 Mac 登录同一账号与工作区，在支持界面的新任务中确认插件可见、可选择。
是否能执行取决于任务提供的运行环境，而不是设备本身。
Mac 关闭仍可在具备相应能力的云端任务中运行。手机端尚需实际验证。
在 Mac 本地安装不代表已经上传到账号；此 ZIP 需要通过账号上传入口安装。
不要把本地目录符号链接误认为跨设备同步。

生成书籍 Skill 与安装本工具插件是两件事。生成文件不会自动成为账号插件；
想复用时可保存在当前私有 GitHub 仓库或另外打包安装。
要随现有仓库保存，请明确告诉 Codex 输出到仓库内 .agents/skills/<slug>，
并说明是否提交和合并到 main。Obsidian 书籍笔记与索引接入属于下一阶段。

插件规则/代码更新时，需要上传新的插件 ZIP；GitHub 源码变化不会更新手动上传包。
Python 依赖属于运行环境，新云端任务应重新检查或通过环境配置重复安装。
