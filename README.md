# Skills

此仓库当前仅保留 Skill 编写模板，尚无实际技能目录。

按用户要求，先前导入的 9 个 Skill 及其来源副本已从当前分支移除。各终端已经安装的技能由对应终端单独管理。

## 模板

新技能模板位于 `templates/skill-template/SKILL.md.template`。创建技能时复制为 `<技能名>/SKILL.md`，填写名称、描述、操作步骤和所需资源。

## 已有本机技能与仓库同步

如果此前将本仓库直接克隆到 `~/.agents/skills/`，本次远端删除会在后续拉取时同步到本机。需要保留现有技能时，应先备份并让本机技能目录独立于此仓库管理，再进行拉取或清理。

本次仓库清理不代表已经访问、修改或解除任何本机目录的 Git 关联。
