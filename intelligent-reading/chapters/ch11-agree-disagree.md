# 第11章：赞同或反对作者

来源：《如何阅读一本书》第11章，艾德勒与范多伦。以下为综合转述。

## 四项批评标准

1. 知识不足：指出缺少哪些相关知识，以及补足后为何会影响结论。
2. 知识错误：指出错误陈述，提供相反的事实依据并说明影响。
3. 不合逻辑：定位缺乏支持的推论、前后矛盾或不能由前提得出的结论。
4. 分析不完整：指出未解决的问题、未处理的关联或尚未展开的理由。

这些对应规则十二至十五。按作者的区分，前三项支持有根据的反对；第四项可支持对完整性暂缓判断。缺陷可以并存，应分别说明。

## 操作模板

作者的具体陈述 → 我的判断 → 文本与事实依据 → 对主要结论的影响 → 判断范围。

评价前还要检查情绪、假设和自己的偏见。不能因为所有人类作品都有局限，就笼统宣布某书不完整；要指出具体问题。一本书的局部事实错误也不自动否定其他无关部分。

## 规则总览

1—4：分类、整体、部分、问题。5—8：词义、主旨、论述、解答。9—11：理解后评价、理性讨论、区分知识与意见。12—15：知识不足、知识错误、不合逻辑、分析不完整。
