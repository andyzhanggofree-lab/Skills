# 术语表

定义为综合转述，保留作者框架。为便于检索按术语 Unicode 顺序排列。

- **主动阅读** — 以合适顺序提出合适问题，并从文本中努力回答。（[第5章](chapters/ch05-demanding-reader.md)）
- **主旨** — 作者借句子表达的判断或主张；不等于句子字面形式。（[第9章](chapters/ch09-propositions-arguments.md)）
- **主题阅读** — 围绕共同问题组织多部作品，比较回答并分析议题。（[第20章](chapters/ch20-syntopical-reading.md)）
- **分析阅读** — 系统理解单部作品的结构、内容与论证，并作公正评价。（[第2章](chapters/ch02-reading-levels.md)）
- **基础阅读** — 处理字词、句子及字面理解的阅读层次。（[第3章](chapters/ch03-elementary-reading.md)）
- **实用性作品** — 关注行动目标、规则和方法，以及其依据的作品。（[第13章](chapters/ch13-practical-books.md)）
- **想象文学** — 借助人物、事件、意象等呈现经验的文学作品。（[第14章](chapters/ch14-imaginative-literature.md)）
- **检视阅读** — 在有限时间内把握书籍类型、主题与结构。（[第4章](chapters/ch04-inspectional-reading.md)）
- **概念笔记** — 记录概念、作者观点、理由和读者思考的笔记。（[第5章](chapters/ch05-demanding-reader.md)）
- **理论性作品** — 主要解释事物是什么、为什么如此的作品。（[第6章](chapters/ch06-classifying-books.md)）
- **知识不足** — 缺少与所论问题有关且影响结论的知识。（[第11章](chapters/ch11-agree-disagree.md)）
- **知识错误** — 具体主张与相关事实不符，需说明依据与影响。（[第11章](chapters/ch11-agree-disagree.md)）
- **粗浅的阅读** — 第一次读困难作品时先连续阅读，建立全貌再研究疑难点。（[第4章](chapters/ch04-inspectional-reading.md)）
- **结构笔记** — 记录书籍类型、主题和组织方式的笔记。（[第5章](chapters/ch05-demanding-reader.md)）
- **论述** — 一组提供结论依据或理由的相关主旨。（[第9章](chapters/ch09-propositions-arguments.md)）
- **词义共识** — 理解作者怎样使用重要词汇，不只查到词典释义。（[第8章](chapters/ch08-shared-terms.md)）
- **辅助阅读** — 使用经验、其他书籍、导读和工具书帮助理解正文。（[第12章](chapters/ch12-reading-aids.md)）
- **辩证的客观** — 尽量公平呈现各方观点，避免预设立场并持续核对原文。（[第20章](chapters/ch20-syntopical-reading.md)）
- **辩证笔记** — 跨书整理共同问题、各方回答和议题关系的笔记。（[第5章](chapters/ch05-demanding-reader.md)）
