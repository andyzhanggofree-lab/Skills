# 阅读判断速查

| 当前情况 | 下一步 | 为什么 | 来源 |
| --- | --- | --- | --- |
| 不知道是否值得读 | 检视书名、序言、目录、索引、重点章节与结尾 | 用较少时间建立阅读方向 | 第4章 |
| 字词和句子本身不懂 | 先处理语言理解障碍 | 更高层次依赖基础能力 | 第3章 |
| 首次读难书被局部卡住 | 建立全貌，记录疑难点，之后回头研究 | 局部需要整体语境 | 第4章 |
| 能背原句但不能解释 | 换一种表达，举具体例子并说明联系 | 区分记住用字与理解思想 | 第9章 |
| 划线很多却说不清全书 | 概括整体并重建部分关系 | 内容摘录不自动形成结构 | 第7章 |
| 同一个词似乎出现不同意思 | 按语境分别记录用法 | 同词不必同义 | 第8章 |
| 想赞同或反驳却说不出理由 | 先公平重述作者论证 | 理解是评价的前提 | 第10章 |
| 发现局部错误 | 查证并说明对主要结论的影响 | 避免过度泛化 | 第11章 |
| 想用摘要代替原书 | 明确实际范围，核对正文 | 摘要可能错漏并限制理解 | 第12章 |
| 同意实用书却不知怎么用 | 明确目标、方法、适用对象与当前条件 | 原则须在情境中判断 | 第13章 |
| 读诗第一句就卡住 | 先读完整首，再朗读重读 | 声音和整体经验帮助理解 | 第15章 |
| 不同历史书解释不同 | 比较范围、资料与视角 | 选择和解释影响叙述 | 第16章 |
| 专业论文超出背景知识 | 说明边界并补专业基础 | 原书不提供全面专业训练 | 第17章 |
| 与哲学作者前提不同 | 暂按其前提理解，再分别评价前提和推论 | 避免未理解就否定 | 第18章 |
| 多本书看似矛盾 | 先对齐词义、问题，再整理议题 | 可能是假分歧 | 第20章 |
| 重读时发现新关系 | 对照以前笔记，说明理解变化 | 重读可能继续拓展认识 | 第21章 |

## 阅读投入选择

字面困难 → 基础；筛选与全貌 → 检视；单书深度理解 → 分析；跨书问题 → 主题。

## 评价顺序

理解作者 → 核对词义与假设 → 重建理由 → 检查事实与推论 → 说明意义。

## 主题阅读提醒

先筛选材料，后找相关章节。统一术语时保留差异。每个观点都有出处；推断要标明。先公平呈现讨论，再按用户需要提供判断。
