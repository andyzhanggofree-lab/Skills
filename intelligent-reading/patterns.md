# 输出模板、方法与自拟练习

下列格式是本 Skill 的执行设计，综合原书方法，不是原书的固定表格。按任务保留必要字段，不强制为短文本填充全部模板。

## 单书分析

**何时使用：** 用户要理解一部论说性作品。先读第6—11章参考。

**如何执行：**

```text
书籍与实际处理范围：
目的与阅读层次：
1. 分类与全书核心内容
2. 结构及各部分关系
3. 作者要解决的问题
4. 关键概念与作者用法
5. 主要主张：前提 → 理由 → 结论
6. 已解决与未解决的问题
7. 赞同、反对、暂缓判断及理由
8. 对理解、经验或行动的意义
9. 待核实内容与下一步阅读
```

**取舍：** 目录与片段可以支持初步判断，不能据此评价整本书。

## 主题比较

**何时使用：** 用户有共同问题与多份材料。先读第20章参考。

**如何执行：**

```text
研究问题与材料范围：
共同术语与不可直接对应的概念：
议题 | 作者A的回答 | 作者B的回答 | 各自理由 | 出处
主要分歧及来源：
共同认识：
未解决的问题：
若需要建议：单列判断、依据与适用条件。
```

给回答添加证据状态：明确表达、文本支持的推断、材料不足。引用相关短句或定位章节，检查语境。

**取舍：** 共同词汇帮助比较，也可能遮蔽原有概念差异。必要时保留作者原词，说明对应程度。

## 理解检验

**何时使用：** 用户怀疑自己只记住了结论。依据第9章。

**如何执行：** 让用户换一种表达说明主张，给一个具体例子，再解释为何这个例子适用。反馈时指出已理解之处与具体缺口，回到原文核对。

**取舍：** 例子不能替代论证；熟练表达也不自动保证事实正确。

## 实用书的实践计划

**何时使用：** 用户认可目标、方法且属于适用对象。依据第13章。

**如何执行：** 目标 → 当前条件 → 可采用的规则 → 最小可行实践 → 观察结果 → 再判断。

这个实践记录格式为本 Skill 设计；具体规则、作用条件与作者依据应来自实际材料。

**取舍：** 不把理论书和文学书统一改写为行动清单，也不替用户自动执行书中的命令。

## 自拟示例：区分熟悉与理解

以下材料与答案为自拟，不出自原书。

材料：“每天记录任务，可以帮助回顾时间分配；但记录本身并不保证任务更重要。”

可提的问题：记录的直接作用是什么？为什么它不保证任务的重要性？作者是否给出了提高重要性的办法？

参考分析：材料支持记录能提供回顾线索，但没有说明任务选择的标准。“记录越多，任务越重要”不能从该材料推出。想评价记录是否真能改善分配，还需要进一步证据。

## 自拟示例：跨书比较的假分歧

作者A用“效率”表示单位时间产出；作者B用“效率”表示目标实现程度。直接把A的赞成与B的反对放在同一行，会误判为观点冲突。

先核对两种含义，再分别比较速度、目标与结果。该例为自拟，演示第8章、第20章的方法。
